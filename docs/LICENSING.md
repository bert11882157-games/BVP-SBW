# Existing licenses and attribution

This import preserves the original notice files; it does not relicense the project.

- `sbw/LICENSE` contains the Superb Warfare code license. The retained upstream README files
  separately describe resource ownership and link to the original project.
- BVP's current mod metadata declares `All Rights Reserved`.
- `bvp/LICENSE.txt` and `bvp/CREDITS.txt` are inherited Forge/MDK notices. Their presence is not
  a project-wide grant covering BVP's own code or imported vehicle assets.
- Third-party model, texture, sound, and dependency permissions need review before public hosting.

Before the first public upload, confirm the intended BVP source license and the permissions for
the assets being redistributed. Keep all applicable notices and attribution with the source.
