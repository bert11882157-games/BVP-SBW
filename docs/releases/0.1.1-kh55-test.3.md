# KH-55 testing build 3

The bottom-right weapon HUD now uses the same selectable weapon list as primary/secondary
controls. Eight fitted KH-55 missiles appear once with their combined ammunition count.
Legacy per-mount entries and native feeds hidden behind a munition group are excluded before
their weapon data is resolved. Each physical bay retains its own coordinates and launch order.

Loaded-pylon reads reuse an entity-owned layout and fitted weapon groups. Layouts refresh on
definition/catalogue changes; groups refresh on equipment/ammunition revisions. Native pod
counts are read live, so firing and reloading cannot leave stale totals. Stable reads no longer
rebuild every mount/group or serialize the store JSON for each weapon lookup. Thin seeker/point
updates share the accepted read-only catalogue instead of deep-copying it.

The matching FFA build reduces KH-55's horizontal range to **1,500 blocks**. Retains the supplied
model, bomb-bay release, eight independently targeted missiles, two launches per second,
128-flare magazine, increased roll rate, radar/faction changes and upstream ground-jitter fix.

Install BVP **0.1.1-kh55-test.3**, SBW **0.8.9-bvp.4**, and FFA **1.0.5-bvp.4** together on
clients and server, with the regular dependencies including meshloader 0.1.1 and Dominions 1.0.11+.

The release records the supported source-build gates, focused regression tests and isolated
loadout-read measurements. These measurements concern CPU work in the tested code path;
they do not establish an FPS gain. Minecraft was not launched. Follow the
[flight and performance checks](../TU95_CRUISE_TESTING.md) before treating this prerelease as stable.
